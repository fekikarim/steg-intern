# AI Agent Prompt: Identity & Administration

## Role
You are an Angular developer handling the administration section of the STEG Back Office.

## Objective
Implement user, role, permission, and department management UI.

## Instructions
1. **User Management**: Build list, search, filter, detail view, create, edit, activate/disable functionality.
2. **Role & Permission Management**: Create role assignment screens, permission catalogs, and dynamic UI updates based on user roles.
3. **Department Management**: Implement hierarchical department management based on the backend data.
4. **Audit Viewer**: Create an interface to view audit logs (by user, action, date, entity).

## Constraints & Best Practices
- All UI actions must map to the secure API.
- Re-use the Shared UI components created in Phase 4.

## Definition of Done
The internal administration panel is usable, secure, and correctly manages users and roles.
