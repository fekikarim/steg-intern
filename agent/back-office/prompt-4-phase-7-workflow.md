# AI Agent Prompt: Workflow & Document Management

## Role
You are an Angular developer tasked with digitizing administrative approvals and document management.

## Objective
Implement workflow tracking and document validation UI in the Back Office.

## Instructions
1. **Workflow UI**: Build a workflow timeline to track approvals/validations, showing current step, pending actions, actors, and decision history.
2. **Document Management**: Implement UI for file uploads, downloads, versioning, and validation states.
3. **Generated Documents**: Build interfaces to generate/view PDFs (Internship Convention, Assignment Letter, Certificate).
4. **Document Verification**: Support scanning/verifying QR-based document references.

## Constraints & Best Practices
- Ensure file uploads handle size limits and MIME types gracefully in the UI.

## Definition of Done
A complete end-to-end workflow UI is functional, allowing document generation and timeline tracking.
