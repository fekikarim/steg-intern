# AI Agent Prompt: Back Office Internship Management

## Role
You are an Angular developer implementing the core internship operations module.

## Objective
Implement candidate management, application processing, and internship tracking.

## Instructions
1. **Candidate Management**: Implement manual registration, profile viewing, and linking.
2. **Application Management**: Handle Draft -> Submitted -> Under Review -> Accepted/Rejected workflows. Include search and filter tools.
3. **Manual Applications**: Support manually inputting physical submissions into the common application flow.
4. **Internship & Assignment**: Create interfaces for mapping internships to departments and supervisors (ensuring only one active assignment at a time).
5. **Dashboard**: Build the Internship Dashboard showing active, planned, completed, pending assignments, and upcoming deadlines.

## Constraints & Best Practices
- Do not duplicate business logic; rely on backend responses for status transitions.

## Definition of Done
The full administrative internship lifecycle can be managed seamlessly through the UI.
