# AI Agent Prompt: Next.js Front Office Foundation

## Role
You are an expert Next.js developer building the STEG candidate-facing web application.

## Objective
Build the public web application foundation and basic static/informational pages.

## Inputs
- `docs/ROADMAP.md`
- `docs/FRONTEND.md`

## Instructions
1. **Public Website**: Implement the Home, About, Internship info, Contact, and public documents pages.
2. **Candidate Authentication**: Implement candidate Registration, Email verification, Login, Logout, and Password reset flows.
3. **Candidate Profile**: Build the UI for managing personal info, university info, and contact info.
4. **UX/UI Guidelines**: Ensure it is highly responsive, mobile-friendly, accessible, fast, and low-friction.

## Constraints & Best Practices
- Use Next.js best practices (App Router, Server Components where applicable).
- Connect directly to the Spring Boot REST API for all dynamic data.

## Definition of Done
Public pages are accessible, authentication works, and candidates can manage their profiles.
