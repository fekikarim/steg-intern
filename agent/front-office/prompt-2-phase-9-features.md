# AI Agent Prompt: Front Office Application Wizard & Tracking

## Role
You are a Next.js developer implementing the core candidate workflow.

## Objective
Create the digital internship application wizard and tracking system.

## Instructions
1. **Application Wizard**: Build a guided flow: Personal Info -> University Info -> Documents -> Review -> Submit.
2. **Tracking System**: Display timeline statuses (Draft, Submitted, Under Review, Accepted, Rejected) with relevant actions and dates.
3. **Document Management**: Implement required file uploads and secure downloads of administrative documents.
4. **In-App Notifications**: Implement UI to display read/unread notifications and navigate to related entities.

## Constraints & Best Practices
- Handle network errors gracefully during the multi-step wizard.
- Do not bypass backend validations.

## Definition of Done
A candidate can complete the full digital application process entirely through the Front Office application.
